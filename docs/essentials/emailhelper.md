### Fast SMTP Transporters
`NE_EmailHelper` wraps NodeJS `nodemailer` allowing you to send dynamic HTML emails instantly via the framework's internal connection pool, rather than reloading the SMTP connection on every single request.

#### Basic Usage
First, ensure that your `.conf` file generated by the Setup Wizard contains the active SMTP details. The `sv-nex` system will connect the pool silently behind the scenes.

```javascript
const { NE_EmailHelper } = require('sv-nex');

const triggerRecoveryEmail = async (userEmail, recoveryCode) => {
    // Note: Template parsing logic can be injected here
    const htmlBody = `<h1>Your code is ${recoveryCode}</h1>`;
    
    // Automatically uses the global configuration SMTP host
    await NE_EmailHelper.sendEmail(
        userEmail, 
        "Password Recovery", 
        htmlBody
    );
};
```

#### Template Sending (Advanced)
If you built rich HTML templates locally, `NE_EmailHelper` provides methods to pull those locally hosted templates, format them dynamically via string replacement or template engines, and execute the delivery queue safely.

> **Note:** If SMTP credentials fail, the `NE_EmailHelper` will throw a framework-level `ApplicationError` tracking the trace, meaning you do not have to handle `try/catch` mailer configurations directly yourself.
